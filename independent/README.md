# Historical rewrite checkpoints

The JSON reports here identify earlier independent interpreter checkpoints. Their
source hashes, test paths and timings describe those saved checkpoints, not the
current release. Async-to-sync reports are not comparisons with frozen v0.2.1.

Executable tests now live under `tests/`. Original behavior disposition and approved
differences are in `tests/legacy/INVENTORY.md`. Delivery uses the normal synchronous
`slip` package. Current acceptance is recorded in `plan/STATUS.md` and release
benchmark reports.
